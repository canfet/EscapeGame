# GPS 實境解謎闖關系統

用 GPS 定位打卡解鎖題目的實境解謎系統。學生**不用登入**，關主可以建立多個闖關專案，換地點時複製專案再改座標就能用。

- **前台／後台頁面**：GitHub Pages（免費、HTTPS、學生不會碰到 Google 登入）
- **API**：Google Apps Script
- **資料**：Google 試算表（所有紀錄都在這裡，可直接篩選、下載）
- **照片**：Google 雲端硬碟

完整設計請看 [DESIGN.md](DESIGN.md)。

## 部署步驟（約 15 分鐘）

### 步驟 1：建立試算表與 Apps Script

> 建議用**個人 Gmail** 帳號操作。學校帳號可能沒辦法把網頁應用程式開放給「所有人」。

1. 到 Google 雲端硬碟新增一份 **Google 試算表**，命名例如「實境解謎資料庫」。
2. 上方選單「擴充功能 → Apps Script」。
3. 把編輯器裡預設的 `程式碼.gs` 內容全部刪掉，貼上 `apps-script/Code.gs` 的內容，按 💾 儲存。
4. （選用）左側「專案設定 ⚙️」→ 勾選「在編輯器中顯示 appsscript.json」，把內容換成 `apps-script/appsscript.json`。至少確認時區是 `Asia/Taipei`。
5. 上方函式下拉選單選 `setup` → 按「執行」。
   - 第一次會要求授權：選你的帳號 →「進階」→「前往（不安全）」→「允許」。
   - 執行完成後，看下方「執行記錄」會顯示 **管理密碼**，請記下來。
6. 回到試算表重新整理，會看到 `Projects`、`Stages`、`Sessions`、`Submissions` 四張工作表和一個示範專案，上方也多了「🧩 實境解謎」選單。

### 步驟 2：部署成網頁應用程式（API）

1. Apps Script 右上角「部署 → 新增部署作業」。
2. 齒輪選「網頁應用程式」。
3. 設定：
   - 執行身分：**我**
   - 誰可以存取：**所有人**
4. 按「部署」，複製「網頁應用程式網址」（結尾是 `/exec`）。

> ⚠️ 之後若修改 `Code.gs`，要到「部署 → 管理部署作業 → ✏️ 編輯 → 版本：新版本 → 部署」，網址不變，修改才會生效。

### 步驟 3：放到 GitHub Pages

1. 在 GitHub 建立一個新的 **Public** repository，例如 `gps-quest`。
2. 把整個資料夾的檔案上傳（可以直接在網頁上拖曳上傳）。
3. 編輯 `config.js`，把 `API_URL` 換成步驟 2 的網址：
   ```js
   window.APP_CONFIG = {
     API_URL: 'https://script.google.com/macros/s/AKfy.../exec',
     SITE_NAME: 'GPS 實境解謎'
   };
   ```
4. repository 的「Settings → Pages」→ Source 選「Deploy from a branch」→ Branch 選 `main`、資料夾 `/ (root)` → Save。
5. 等 1～2 分鐘，網址會是：
   - 前台：`https://你的帳號.github.io/gps-quest/`
   - 後台：`https://你的帳號.github.io/gps-quest/admin.html`

> `apps-script/` 資料夾也會被公開，但裡面沒有任何密碼或答案，不影響安全。介意的話可以不上傳這個資料夾。

### 步驟 4：測試

1. 開後台，輸入管理密碼登入。
2. 示範專案的三關都設了通關碼 `1111`、`2222`、`3333`，人不在現場也能測完整流程。
3. 用「複製」建立你自己的專案，修改關卡座標後，狀態設 `hidden` 到現場實測。

## 日常使用

| 我想… | 怎麼做 |
|---|---|
| 換一個地點辦活動 | 後台「專案」→「複製」→ 到「關卡」改座標 |
| 決定這次玩哪個專案 | 給學生 `index.html?p=專案代碼` 的連結或 QR Code；或把專案設為「預設」 |
| 同一路線辦好幾場 | 產生連結時填「場次代碼」，紀錄會自動分開 |
| 看學生傳了什麼 | 後台「闖關紀錄」，或直接看試算表 `Submissions`；照片在雲端硬碟「GPS實境解謎_上傳照片」 |
| 直接改試算表 | 可以！改完約 30 秒內生效，或按選單「套用修改」 |
| 忘記管理密碼 | 試算表選單「🧩 實境解謎 → 顯示管理密碼」 |
| 換管理密碼 | 試算表選單「重設管理密碼」 |

## 常見問題

**前台顯示「伺服器回應格式錯誤」**
Apps Script 部署時「誰可以存取」不是「所有人」，或修改程式後沒有部署新版本。

**定位一直說太遠／誤差太大**
請學生到空曠處，手機開啟「精確位置」；後台可以把該關半徑放大，或專案的「可接受定位誤差」調高，或改用現場通關碼。

**iPhone 沒有跳出定位詢問**
設定 → 隱私權與安全性 → 定位服務 → Safari 網站 → 「使用 App 期間」，然後重新整理頁面。

**學校網路打不開**
少數學校防火牆會擋 `github.io` 或 `script.google.com`，請活動前用學生裝置和學校網路測試，必要時改用手機網路。

**地圖沒有顯示**
地圖使用 OpenStreetMap，若網路擋住地圖圖磚，關卡功能仍可正常使用（距離與打卡不受影響）。
