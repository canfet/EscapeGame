# PRD：實境解謎「體驗套版」升級

## 1. Original Requirement
> 幫我升級EscapeGame的畫面，希望讓實境解謎可以更生動的玩法，來吸引使用者的注意，要有良好的使用者體驗或是用成RGP的角色模式，希望有多種套版，可以讓使用者設定不同的實境解謎看到的呈現效果或不一樣

## 現況
- 前台為靜態網頁（GitHub Pages）＋ Google Apps Script 後端，無建置步驟（純 HTML/CSS/JS）。
- 專案已有 `theme`（8 種**換色**主題）：只改顏色、字體、地圖濾鏡；玩法文字、HUD、動態效果完全相同。
- 已有：隊伍造型（動物 emoji）、教學、抵達動畫、過關畫面、圖鑑卡牌、徽章／稱號、密碼碎片。

## 2. Product Goals
1. 讓一個專案只改一個設定（「體驗套版」），就能換掉**整套呈現**：用語、HUD、開場劇情、特效、過關畫面，而不只是顏色。
2. 提供 RPG 角色模式：玩家選職業、隊伍有等級與經驗值條、NPC 對話推進劇情，過關有升級動畫。
3. 不退步：未設定套版的既有專案行為與現在**完全一致**；特效可關閉、尊重「減少動態效果」、低階手機不卡頓。

## 3. User Stories
1. 身為**關主**，我想在後台為每個專案選一種體驗套版並即時預覽，以便不同活動（校慶、古蹟、夜間）有不同氛圍。
2. 身為**關主**，我想為專案設定 NPC 名字與頭像，以便用角色口吻帶玩家進入劇情。
3. 身為**玩家**，我想在 RPG 套版選擇職業、看到等級／經驗值成長，以便有角色養成的成就感。
4. 身為**玩家**，我想在開場與過關時看到 NPC 對話逐字出現，以便沉浸在故事裡，而不是看一大段文字。
5. 身為**玩家**，我想抵達、過關、完賽時有符合氛圍的動畫與特效，以便獲得明確的回饋。
6. 身為**玩家**（手機較舊或怕暈），我想一鍵關閉特效，以便畫面流暢、不干擾解謎。

## 4. Competitive Analysis
- Actionbound：模板化任務、介面統一，缺少角色養成與套版氛圍切換。
- Pokémon GO 類 AR 遊戲：角色養成強、沉浸感高，但需要大量素材與開發，不適合關主自行配置。
- Google 表單／試算表闖關：設定簡單，但呈現完全沒有遊戲感。
- 現有 EscapeGame（換色主題）：易設定，但「換皮不換玩法」，吸引力有限。
- 本方案定位：維持「關主零程式設定」的前提，用資料驅動的套版達到遊戲化呈現。

## 6. Acceptance Criteria（P0）
- R1：
  - `adminSaveProject` 傳入非法 `template` 回 `BAD_INPUT`；合法值寫入 Projects 試算表 `template` 欄（舊試算表自動補欄）。
  - `publicProject_` 回傳 `template`；舊專案（空值）回 `classic`。
  - 前台 `body` 有 `tpl-<id>` class；`classic` 時畫面與升級前無差異（無新增可見元素）。
- R2：
  - 建立隊伍時顯示 ≥6 種職業；選擇的職業存為 session.avatar，後端接受（白名單含職業）。
  - HUD 顯示 `Lv.N` 與 EXP 條：Lv = 1 + 已完成關卡數；EXP 條 = 目前分數 / 全部關卡總分。
  - 完成關卡後過關畫面出現「LEVEL UP」動畫與新等級。
- R3：
  - 專案可存 `npc_name`、`npc_avatar`（≤20 字）；前台在 rpg／detective／agent 套版的開場與過關顯示對話框，逐字輸出；點擊對話框立即顯示全文，再點關閉。
  - classic 套版不顯示對話框。
- R4：
  - 特效層為單一 `<canvas>`，`pointer-events:none`；`prefers-reduced-motion` 或玩家關閉時完全不啟動動畫迴圈。
  - 分頁隱藏（`visibilitychange`）時暫停；粒子數量上限 ≤ 40。
  - 開關狀態存 `localStorage`，重新整理後保留。
- R5：
  - detective：標題用「案件」用語；過關時有「SOLVED」印章蓋下動畫。
  - agent：等寬字體、終端機式標題；開場文字逐字輸出。
- R6：
  - 後台專案表單有套版下拉＋預覽；切換時預覽即時更新；儲存後重開表單值正確。
  - NPC 欄位只存入專案，不影響舊專案。

## 7. UI/UX Draft
- **後台**：專案表單「前台畫面風格」上方新增「體驗套版」下拉（🗺 經典／⚔️ RPG 角色冒險／🕵️ 偵探案件／🛰 特務任務）與一張預覽卡（套版名稱、一行說明、用語範例、特效），下方「NPC 名稱／頭像」兩欄。
- **前台 RPG**：建立隊伍頁的「隊伍造型」改為「選擇職業」（⚔️戰士、🧙法師、🏹遊俠、🗡️盜賊、🛡️聖騎士、🩺牧師、🎻吟遊詩人、🐉龍裔），HUD 顯示 `⚔️ 隊名 Lv.3`，下方金色 EXP 條。「下一站」改為「下一個任務」。過關時全螢幕「LEVEL UP」＋升級光效，NPC 對話框在畫面下緣。
- **偵探**：卷宗紙紋、手寫標題、過關蓋紅色「SOLVED」印章。
- **特務**：黑底綠字終端機、`> ` 提示符、開場逐行輸出。
- **海盜寶藏**：航海日誌羊皮紙、船長 NPC、過關時金幣灑落、用語「航段／寶藏／船員」。
- **魔法學院**：學院徽章、漂浮星光、用語「課程／學分／咒語」，過關有星光爆發與「學分 +N」。
- **右上角**新增 ✨ 特效開關（和 🔊 並列）。

## 8. Assumptions & Open Questions
- 「使用者設定」＝關主在後台設定（每個專案一個套版）；玩家只能開關特效，不能自行換套版。
- 套版與既有 8 種色彩主題**正交**：24+ 種組合；套版只提供「建議主題」。
- 不引入新的後端資料表；只新增 Projects 欄位 `template`、`npc_name`、`npc_avatar`。
- 不引入新的外部套件與圖片素材（全部用 CSS／emoji／Canvas），維持無建置、離線友善。
- 職業沿用 `Sessions.avatar` 欄位儲存（emoji），不新增欄位。
- 等級／經驗為前台由進度即時計算，不另存。
